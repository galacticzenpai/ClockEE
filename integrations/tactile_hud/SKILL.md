# Keyboard-First Cockpit Shortcuts & Accessibility HUD

Reel: #16 (https://www.instagram.com/p/DebmIDlSiR3/)
Package: `integrations/tactile_hud/`

## Keymap Standard (NTA Aligned)
- `1`, `2`, `3`, `4`: Select Option A, B, C, D
- `S` or `Enter`: Save & Next Question
- `M` or `R`: Mark for Review & Next
- `C` or `Backspace`: Clear Selected Response
- `P` / `LeftArrow`: Previous Question
- `N` / `RightArrow`: Next Question
- `?`: Toggle Tactile HUD Shortcut Legend

## Latency Target
Dispatches action listeners within <2ms of keydown event without input lag or ghosting.
