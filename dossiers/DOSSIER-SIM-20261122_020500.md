## 2. Defect Breakdown & Reproduction Steps

### DEFECT-1 (Severity: P1 — Major UI / UX Functional Gap)
- **Title**: Missing Interactive 50-Step Accordion Hierarchy in Conversation Logs & Node Incompleteness
- **Location**: `#view-logs` -> `#logs-cards-container`
- **Expected Behavior**:
  1. All 10 active mesh nodes should be listed in the Conversation Logs inspector.
  2. Clicking an agent node card should expand an interactive step timeline displaying 50 chronological steps.
  3. The latest step (Step 50 / N) should be expanded by default showing step title, tool calls, model output, and timestamp.
  4. The prior 49 historical steps (Steps 1..49) should be collapsed as sleek accordion items that toggle open individually on click.
- **Observed Behavior**:
  1. The inspector reports "Showing 4 of 4 nodes" (only Planner, Backbone, GitHub, and Main Feature are displayed; UI/UX, Simulation, Bug Fix, DB, QA, and Innovation are missing).
  2. Clicking a node card merely expands a raw JSON `<pre><code>` dump of the entire object (including `"logs_50": [...]`). There is no modular accordion UI.
- **Evidence Screenshot**:
  `final_step_88.png` ([Screenshot file](file:///C:/Users/Kunal/.gemini/antigravity/brain/56a83a63-c595-4bc7-a564-5defc1766715/browser_evidence/19bbd96b-5491-4ef8-81ef-ec1250299479/final_step_88.png))
- **Remediation Suggestion**:
  - In `antigravity_manager.html` inside `renderConversationLogs()`:
    * Iterate over all 10 nodes from `currentMeshState.nodes`.
    * If `node.logs_50` or `node.steps` exists, render a dedicated `.step-accordion-list`.
    * Render Step 50 as `.step-accordion-item.expanded` and historical steps with `.step-accordion-item.collapsed` with an `onclick="toggleStepItem(stepNum)"`.

### DEFECT-2 (Severity: P2 — Interactivity Gap)
- **Title**: Moving Transmission Orbs & Synaptic Paths Lack Event Handlers for Transmission Payload HUD
- **Location**: `#view-overview` -> `#mesh-svg-canvas` -> `path.pulse-vector`, `circle.pulse-orb`
- **Expected Behavior**:
  - Hovering or clicking on an animated transmission orb or synaptic vector should open a sleek HUD modal/popover displaying the active transmission payload:
    * Sender node
    * Target node
    * Channel name / Synapse ID
    * Timestamp
    * Message / Payload snippet
- **Observed Behavior**:
  - Particle orbs animate along `<path>` elements via `<animateMotion>`, but have no attached `onclick`, `onmouseenter`, or cursor styling.
  - Clicking on orbs or paths produces no response or HUD display.
- **Evidence Screenshot**:
  `step_71_shot_1.png` ([Screenshot file](file:///C:/Users/Kunal/.gemini/antigravity/brain/19bbd96b-5491-4ef8-81ef-ec1250299479/browser_sandbox/screenshots/step_71_shot_1.png))
- **Remediation Suggestion**:
  - Add an SVG click listener or `data-transmission-id` to the animated orbs/paths.
  - Implement a `showTransmissionHUD(sender, target, payload)` popover anchored near the click coordinates or in a floating HUD card.

### DEFECT-3 (Severity: P2 — Cloud Telemetry Reliability)
- **Title**: Header Badge Drops to `● CACHED (OFFLINE FALLBACK)` on Cloud Deployment
- **Location**: `#mesh-sync-text` / `.telemetry-badge`
- **Expected Behavior**:
  - Real-time polling to `mesh/manager_state.json?t=<timestamp>` should return HTTP 200 and display `● 10 NODES SYNCED [LIVE]`.
- **Observed Behavior**:
  - Header badge displayed `● CACHED (OFFLINE FALLBACK) 1:37:41 AM` during the live audit run.
  - Indicates that the cloud runtime fetch to `mesh/manager_state.json` aborted, timed out, or returned 404, triggering fallback to localStorage cache.
- **Remediation Suggestion**:
  - Verify that `mesh/manager_state.json` is deployed and accessible at the root of `https://antigravity-mesh-cockpit.vercel.app/mesh/manager_state.json` without routing restrictions.
  - Extend fetch timeout from 2500ms to 4000ms in `fetchMeshState()`.
