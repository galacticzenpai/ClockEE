# Dynamic Viewport Fluid Math & Reading Typography System

Reel: #19 (https://www.instagram.com/p/DeRiLg-iah2/)
Package: `integrations/fluid_typography/`

## Capabilities
- Computes mathematically exact CSS `clamp(min, preferred, max)` rules based on viewport bounds (320px to 1920px).
- Prevents awkward text-wrapping in complex equations, fraction bars, and multi-line MCQs.
- Automatically injects fluid variables into `cbt_shared.css`.
