# Millisecond-Accurate Exam Session Action Playback & Scrubbing

Reel: #21 (https://www.instagram.com/p/DfPfsMENJyB/)
Package: `integrations/rrweb/`

## Capabilities
- Records timestamped user interactions:
  - Option clicks
  - Question switches
  - Save & Next actions
  - Mark for review toggles
  - Clear answer events
- Low overhead (<1% CPU, <200KB per 3-hour exam).
- Standalone HTML5 scrubber player (`integrations/rrweb/session_player.html`) for post-exam review.
