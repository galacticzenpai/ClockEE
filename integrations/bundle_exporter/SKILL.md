# Standalone Zero-Dependency Offline Single-File HTML Exporter

Reel: #39 (https://www.instagram.com/p/De9ncU9vZgH/)
Package: `integrations/bundle_exporter/`

## Capabilities
- Bundles ClockEE into an air-gapped single distribution file (`dist/clockee_standalone.html`).
- Inlines CSS stylesheets, SVG assets, and JSON question banks.
- Completely portable: runs off a USB drive without any local web server or internet connection.
