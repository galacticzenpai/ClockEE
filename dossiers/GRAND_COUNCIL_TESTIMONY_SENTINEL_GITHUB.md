## 4. Architectural & Deployment Decisions

### A. Two Decoupled Vercel Projects
- **ClockEE Student Platform (`clockee-os-2`):**
  - **URL:** `https://clockee-os-2.vercel.app`
  - **Purpose:** Public student application hosting 15,733 authentic questions, CBT simulation engine, focus chambers, and coaching ledgers.
  - **Air-Gap:** All operator dossiers, mesh IPC state files, and manager cockpits are physically excluded via `.vercelignore`.
- **Antigravity Manager Cockpit (`antigravity-mesh-cockpit`):**
  - **URL:** `https://antigravity-mesh-cockpit.vercel.app`
  - **Purpose:** Private developer & operator flight deck monitoring 10 autonomous agents, bilateral brain visual graphs, and live Gravity Chat channels.

### B. The Mandatory Git Disconnect
Connecting both projects to the same GitHub repository created an architectural trap: pushing to `origin/main` triggered Vercel to rebuild the cockpit from repository root, invoking `api/index.py` and `vercel.json` rewrites meant for the student app. Running `vercel git disconnect --yes` and deploying exclusively from an isolated static bundle (`cockpit_dist/`) permanently resolved this, ensuring the cockpit remains a pure, blazing-fast static dashboard.

### C. Live Pre-Promotion Verification via `vercel curl`
Rather than relying on browser cache or basic HTTP pings:
- Every deployment is audited via `vercel curl -I` to verify the actual edge headers (`X-Vercel-Cache`, `Server: Vercel`, `Content-Type: text/html`).
- All 5 core routes (`/`, `/cbt_exam`, `/timer`, `/tracker`, `/cbt_analysis`) are systematically queried to confirm `HTTP/1.1 200 OK` before signaling release completion.

## 5. Experiences, Roadblocks & Breakthroughs

### The Great Vercel Root Redirect Showstopper
- **Incident:** During the initial cockpit cloud launch, visiting `https://antigravity-mesh-cockpit.vercel.app` returned a 302 redirect to `/login` (the student portal).
- **Forensic Diagnosis:** The root project's `vercel.json` rewrites and Python serverless backend were being pulled into the build because Vercel was auto-detecting the parent git repository.
- **The Breakthrough:**
  1. Created an isolated static distribution harness (`cockpit_dist/`) containing only `index.html`, `styles/`, `mesh/manager_state.json`, and a bare-metal `vercel.json` (`{"cleanUrls": true}`).
  2. Disconnected automatic git hooks for that project.
  3. Deployed directly from inside `cockpit_dist/`.
  4. Verified zero redirects and direct delivery of the 69.5 KB Bilateral Brain Cockpit.
