# LLM-Lint: AI Provenance & Clean Attribution Sanitizer for ClockEE

Adapted from the open-source **`llm-lint`** tool ([`JadenRazo/llm-lint`](https://github.com/JadenRazo/llm-lint), MIT License).

## Overview
When AI coding assistants (Claude Code, Cursor, Codex, Gemini) generate code, pull requests, or commits, they frequently inject tracking trailers, watermarks, and auto-generated boilerplate:
- `Co-authored-by: Claude <noreply@anthropic.com>` in git commits
- `Generated with Claude Code` footers in markdown and pull requests
- Tracking tags and prompt leaks in docstrings (`// Generated by AI assistant`, `/* Prompt: ... */`)
- Accidental tracking directories and session logs committed to Git

`llm-lint` provides ClockEE with a zero-dependency local scanner and automated Git `commit-msg` hook to ensure the repository remains professional, human-crafted, and completely free of automated AI branding.

---

## Detection Rule Set

| Rule ID | Category | Pattern Flagged | Severity |
| :--- | :--- | :--- | :---: |
| **LLM001** | Git Metadata | `Co-authored-by:.*(?:Claude\|Copilot\|ChatGPT\|Gemini)` | 🔴 CRITICAL |
| **LLM002** | Watermark | `Generated with (?:Claude Code\|Cursor\|Copilot\|v0)` | 🟠 HIGH |
| **LLM003** | Code Comment | `(?:Generated by AI\|Created with AI\|Prompt:\|LLM output)` | 🟡 MEDIUM |
| **LLM004** | Artifact Leak | Tracked `.claude/` or temporary prompt artifacts | 🔴 CRITICAL |

## Core Usage Commands

### 1. Scan Repository for AI Watermarks & Leaks
```powershell
python integrations/llm_lint/lint_runner.py scan
```

### 2. Auto-Sanitize Commit Messages
```powershell
python integrations/llm_lint/lint_runner.py sanitize-commit <commit_msg_file>
```

### 3. Install Git Commit-Msg Hook
```powershell
python integrations/llm_lint/lint_runner.py install-hook
```
